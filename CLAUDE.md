# Instruções para o Claude neste projeto

Leia [README.md](README.md) no início de cada sessão neste projeto — é o
resumo de contexto pra retomar o trabalho de onde parou (em qualquer
computador).

**Regra fixa:** depois de qualquer commit com mudança relevante (nova
página, nova função ligada ao Firestore, mudança de modelo de dados,
correção de segurança, decisão de arquitetura), atualize o `README.md`
antes de encerrar a resposta — principalmente as seções **Estado atual** e
**Próximos passos conhecidos**. Não precisa perguntar permissão pra isso;
é parte natural de terminar a tarefa, do mesmo jeito que rodar testes.

Não é preciso registrar mudanças triviais (typo, ajuste de CSS, texto de
um botão) — só o que muda o que alguém pegando o projeto do zero precisaria
saber.
